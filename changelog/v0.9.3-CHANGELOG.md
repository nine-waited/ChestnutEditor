# Chestnut Editor v0.9.3

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器。本版文件树可看到图片与绘图；支持拖入或选择 ZIP 导入 Markdown；标题快捷键可切换层级；文档创建与更新时间改为按需弹出，截图时默认不带时间。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### 下载

| 项目 | 说明 |
|------|------|
| **安装包** | `Chestnut_0.9.3_x64-setup.exe`（Windows x64，NSIS） |
| **系统要求** | 64 位 Windows 10 及以上；缺少 WebView2 时安装程序会自动下载 |
| **默认知识库** | 首次启动打开 `~/.chestnut` |

**构建产物：**

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.9.3_x64-setup.exe`

### v0.9.3 新内容

#### 文件树与导入

- 文件树列出图片和 Excalidraw 绘图，不只显示 Markdown
- 文件夹右键可通过系统选择器导入 Markdown
- 导入选择器同时接受 `.md` 与 `.zip`
- 把 ZIP 拖进窗口即可解压导入，并显示进度

#### 示例文档

- 每个知识库只写入一次默认示例（中英 README、Mermaid 演示）；删除后刷新或重启不会再生成

#### 编辑

- `Ctrl+1`～`Ctrl+6`：同级再按一次退回正文；按不同数字可切换标题层级，并同步井号

#### 文档时间

- MD 刷新按钮左侧增加时钟按钮：点一次弹出创建时间与最后更新，再点一次收起
- 时间不写进笔记文件，也不常驻正文附近，方便截图

### 从 v0.9.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files. This release shows images and drawings in the file tree, imports Markdown from ZIP drops or the file picker, lets heading shortcuts change levels, and keeps created/updated times behind a toggle so screenshots stay clean. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.3

#### File tree and import

- The file tree lists images and Excalidraw drawings, not only Markdown
- Folder context menus can import Markdown through the system file picker
- The import picker accepts both `.md` and `.zip`
- Drop a ZIP onto the window to unpack and import, with a progress dialog

#### Sample notes

- Default samples (Chinese/English README, Mermaid demo) are seeded once per vault; deleting them no longer recreates them on refresh or restart

#### Editing

- `Ctrl+1`–`Ctrl+6`: press the same level again to drop back to body text; press a different number to change heading level and keep the `#` markers in sync

#### Document time

- A clock button to the left of Refresh shows created and last-updated times; click again to hide
- Times are not written into the note file and are not always visible, so screenshots stay clean

### Upgrading from v0.9.x

- No vault migration required
