# Chestnut Editor v0.9.6

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器。本版界面改为灰色底板上的微圆角卡片式布局（浅色 / 深色均适配），并新增统一的查找替换：Ctrl+F / Ctrl+H 在当前页右上角呼出，正文和代码块一起查找、替换。底部状态栏会像 Word / Excel 一样显示选中计数；表格工具栏常驻，并提供一键复制表格；代码块可选 Mermaid；目录右键可复制路径。实时模式的格式符号在输入、撤销时更稳定。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### v0.9.6 新内容

#### 卡片式界面

- 窗口底部为浅灰底板，顶栏、文件栏、编辑区各自是一张白色微圆角卡片，块与块之间留出间距；分屏时左右各为一张卡片
- 标签页改为无边框胶囊样式，当前标签浅灰填充并加粗；状态栏直接落在底板上
- 设置页按「语言 / 字体 / 主题 / 本地存储 / 笔记 / 插件 / 快捷键」分组成卡片，居中显示
- 确认框、导出进度、快速打开与全文搜索去掉描边、加大圆角，背景轻微模糊；按钮改为胶囊样式，确认按钮用强调色
- 输入框、下拉框、右键菜单、代码块与格式工具条的圆角和底色统一
- 深色模式同步适配

#### 字体与更新提示

- 界面字体只保留微软雅黑，移除两款手写字体
- 检查到新版本时，弹窗只保留「关闭」和「更新」两个按钮

#### 查找替换

- Ctrl+F 在当前页右上角打开查找框，Ctrl+H 同时展开替换行；实时模式和源码模式都可用
- 正文和代码块统一查找、高亮和替换，代码块不再弹出单独的查找框，也不会出现浏览器自带的查找条
- 支持区分大小写、全词匹配和正则（替换可用 `$1`、`$&`）；显示「当前 / 总数」，正则写错会提示
- Enter / Shift+Enter 或 F3 / Shift+F3 在匹配间跳转；替换框里 Enter 替换当前，Ctrl+Enter 全部替换，一次 Ctrl+Z 即可整体撤销
- 选中一段文字再按 Ctrl+F 会自动填入并定位到该处；Esc 关闭并选中当前匹配
- 仅查看模式只能查找，不显示替换；分屏时只作用于当前聚焦的一栏

#### 状态栏计数

- 底部常驻显示字数和字符数；选中正文时按 Word 的规则显示「已选择 X / Y 字」
- 选中表格单元格时按 Excel 的方式显示「行 × 列 · 单元格数」，以及计数、求和、平均值

#### 表格

- 表格顶部工具栏常驻显示
- 工具栏最右侧新增「复制表格」按钮，图标与顶栏「复制路径」一致

#### 代码块

- 语言列表新增 Mermaid，显示名为 `Mermaid`

#### 文件栏

- 文件夹右键菜单新增「复制路径」，与文件一致

#### 实时编辑

- 在已有的格式符号之间输入文字时，立即按格式渲染，输入过程中保持渲染
- 撤销 / 重做前先收起已展开的符号，历史记录里不再残留多余的符号
- 刚闭合的格式在光标移回之前保持渲染，按 Enter 时收起

### 从 v0.9.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files. This release moves the interface to softly rounded cards on a gray canvas (light and dark), and adds unified find and replace: Ctrl+F / Ctrl+H opens a panel in the top-right corner of the current page that searches and replaces across body text and code blocks. The status bar shows selection counts like Word and Excel; the table toolbar stays visible and can copy the whole table; code blocks offer Mermaid; folders can copy their path from the context menu. Live-mode format markers are steadier while typing and undoing.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.6

#### Card-style interface

- The window sits on a light gray canvas; the top bar, file bar, and editor are separate white cards with small rounded corners and gaps between them. In split view each pane is its own card
- Tabs become borderless pills; the active tab gets a light gray fill and bold text. The status bar sits directly on the canvas
- Settings are grouped into cards (Language, Font, Theme, Local storage, Notes, Plugins, Shortcuts) and centered
- Confirm dialogs, export progress, quick open, and search drop their borders, use larger corners, and blur the background; buttons become pills with the confirm action in the accent color
- Inputs, selects, context menus, code blocks, and the format toolbar share the same corner radius and fill
- Dark mode is updated to match

#### Fonts and update prompt

- The interface font is Microsoft YaHei only; the two handwriting fonts are removed
- When an update is available, the dialog shows only Close and Update

#### Find and replace

- Ctrl+F opens a find panel in the top-right corner of the current page; Ctrl+H also shows the replace row. Works in both live and source mode
- Body text and code blocks are searched, highlighted, and replaced together; code blocks no longer open their own search box, and the browser find bar no longer appears
- Match case, whole word, and regex (replacement supports `$1` and `$&`); shows "current / total" and flags an invalid regex
- Enter / Shift+Enter or F3 / Shift+F3 move between matches; in the replace box, Enter replaces the current match and Ctrl+Enter replaces all, undone with a single Ctrl+Z
- Selecting text before Ctrl+F fills it in and starts at that match; Esc closes the panel and selects the current match
- View-only mode allows find but hides replace; in split view the panel only acts on the focused pane

#### Status bar counts

- Word and character counts are always shown; selecting body text shows "X of Y words selected" using Word's counting rules
- Selecting table cells shows "rows × columns · cells" plus Count, Sum, and Average, the way Excel does

#### Tables

- The table toolbar stays visible
- A "Copy table" button sits at the right end of the toolbar, using the same icon as "Copy path" in the top bar

#### Code blocks

- Mermaid is now in the language list, shown as `Mermaid`

#### File bar

- Folders gain "Copy path" in the context menu, matching files

#### Live editing

- Typing between existing format markers renders the span immediately and keeps it rendered while typing
- Undo / redo collapses revealed markers first, so history no longer leaves stray markers
- A just-closed format stays rendered until the caret moves back in, and collapses on Enter

### Upgrading from v0.9.x

- No vault migration
