# Chestnut Editor v0.9.1

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器 —— 实时预览里可看见并改标题的 `#`、公式两侧的 `$`，以及加粗等源码符号；从资源管理器拖入 Markdown、复制图片像素也更稳。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### v0.9.1 新内容

#### 实时 Markdown 源码符号

- 光标或指针在对应格式上时，显示灰色源码符号：标题 `#`、加粗 `**`、斜体 `*`、行内代码 `` ` ``、删除线 `~~`、高亮 `==`、行内公式 `$`
- 点进这些符号即可改（例如删掉 `#` 降标题、拆 `**` 取消加粗）
- 标题的 `#` 写入文档，与正文共用同一套光标；删 `#` 会降级，不会被自动写回去
- 用工具栏把文字收成公式后，选中不再弹出带 √ 的确认条，两侧显示 `$`

#### 笔记开头与拖入

- 笔记第一行左侧的加号可在文首插入空段，按钮放在编辑区内边距，不再挤占文件栏
- 从资源管理器把 Markdown 拖到窗口即可导入；配图复制到笔记旁的 `_pic` 文件夹
- 笔记内图片按相对 Markdown 的路径保存，Git 和其他编辑器也能直接显示

#### 图片复制

- 工具栏复制选中图片时写入像素，而不是无法粘贴的 HTML
- 网络图片先下载再按像素复制，避免画布被污染导致复制失败
- 代码块复制后有成功反馈

#### 文件栏与窗口

- 侧栏只列出 Markdown、PDF、ZIP
- 切换知识库文件夹时先 flush 未保存编辑器并重置全部标签
- 切换笔记时收起图片工具栏
- 去掉窗口底部多余的横向滚动条

### 从 v0.9.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files — live view now shows editable source tokens for headings, formulas, and inline marks; Explorer drops and pixel image copy are more reliable. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.1

#### Live Markdown source tokens

- Gray source tokens appear on the caret or pointer: heading `#`, bold `**`, italic `*`, inline code `` ` ``, strike `~~`, highlight `==`, inline math `$`
- Click a token to edit it (delete `#` to demote a heading, split `**` to unwrap bold)
- Heading hashes are real document text and share the live-editor caret; deleting them demotes the heading instead of being restored
- Formatting text as a formula no longer shows a checkmark confirm bar; `$` tokens appear on both sides

#### Note start & drops

- A plus control in the first-line editor padding inserts a blank paragraph above the note without squeezing the file tree
- Drop Markdown from Explorer onto the window to import; images are copied into a sibling `_pic` folder
- Managed note images are stored as Markdown-relative paths so Git and other editors can display them

#### Image copy

- Copy selected images from the toolbar as pixels, not HTML that will not paste
- Download remote images before copying pixels so a tainted canvas cannot fail the copy
- Code-block copy shows success feedback

#### Files & window

- The sidebar lists only Markdown, PDF, and ZIP files
- Switching vault folders flushes unsaved editors and resets all tabs
- Dismiss the image toolbar when switching notes
- Hide leftover horizontal scrollbars at the bottom of the app

### Upgrading from v0.9.x

- No vault migration required
