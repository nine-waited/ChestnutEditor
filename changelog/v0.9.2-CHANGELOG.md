# Chestnut Editor v0.9.2

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器。本版检查更新可直接下载安装包并打开安装程序；顶栏可跳到 GitHub 反馈；实时区改一侧源码符号时高亮等样式不再中途消失。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### 下载

| 项目 | 说明 |
|------|------|
| **安装包** | `Chestnut_0.9.2_x64-setup.exe`（Windows x64，NSIS） |
| **系统要求** | 64 位 Windows 10 及以上；缺少 WebView2 时安装程序会自动下载 |
| **默认知识库** | 首次启动打开 `~/.chestnut` |

**构建产物：**

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.9.2_x64-setup.exe`

### v0.9.2 新内容

#### 检查更新

- 确认更新后从 GitHub Release 下载 Windows 安装包，显示进度，完成后自动打开安装程序
- 下载失败时走镜像重试；没有安装包时仍可打开下载页

#### 顶栏与工具栏

- 检查更新左侧增加「问题反馈」，打开 GitHub Issues
- 字体样式工具栏图标加深；点选后以板栗色高亮
- 顶栏右侧提示向左展开，避免「启动调试日志」等文字越出窗口

#### 实时 Markdown

- 先改后面的源码符号、再改前面时，高亮 / 加粗 / 删除线等样式不再中途消失
- `==` 改到一半（只剩一个 `=`）、`~~` 改到一半时保持原样式；删光一侧才会取消
- Markdown 分割线 `---` 颜色加深，更易辨认

### 从 v0.9.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files. This release can download the installer from Check for Updates and open it; the toolbar links to GitHub Issues; editing one live source token no longer drops highlight and other marks. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### Download

| Item | Details |
|------|---------|
| **Installer** | `Chestnut_0.9.2_x64-setup.exe` (Windows x64, NSIS) |
| **Requirements** | 64-bit Windows 10+; WebView2 (downloaded during install if missing) |
| **Default vault** | `~/.chestnut` on first launch |

**Build output:**

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.9.2_x64-setup.exe`

### What's New in v0.9.2

#### Check for Updates

- After you confirm, download the Windows installer from the GitHub Release with a progress bar, then open the installer
- Retry via a mirror if the download fails; fall back to the download page when no installer is attached

#### Toolbar

- A Feedback button next to Check for Updates opens GitHub Issues
- Format toolbar icons are darker; the active item uses a chestnut highlight
- Right-side toolbar tooltips expand left so labels such as Start debug log stay inside the window

#### Live Markdown

- Editing the trailing source token before the leading one no longer drops highlight, bold, or strike
- Mid-edit tokens such as `=` from `==` or `~` from `~~` keep the current style until you clear a side
- Markdown horizontal rules (`---`) are darker and easier to see

### Upgrading from v0.9.x

- No vault migration required
