# Chestnut Editor v0.5.0

---

## English

A desktop editor for local Markdown and Excalidraw files — split panes, pinned notes, richer file-tree workflows, and a sharper global search.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.5.0

#### Split editing

- **Left / right split** from the toolbar (next to always-on-top)
- Multi-tab: the active note moves to the right pane; a single (or empty) tab stays left with an empty right pane
- Closing all tabs on either side does **not** exit split — only the toolbar toggle does
- Draggable center divider; notes are exclusive across panes (same file cannot open on both sides)
- Long-press drag tabs between panes; tab close buttons are borderless / transparent

#### Outline drawer

- Markdown outline uses the same collapsible drawer pattern as the file tree
- Left and right panes keep **independent** outline width / collapsed state
- Split mode: outlines start collapsed; single-pane mode: outline starts open

#### Pinned area

- Link-style **Pinned** bar above the file tree (does not move real files)
- Pin / unpin from Markdown and Excalidraw context menus; drag to reorder; drag from the tree to pin
- Multi-select in the pinned bar; batch unpin; re-pin to move an item to the top
- Hidden when empty; adjacent to the file list (no overlay)
- Selecting a pinned item highlights the matching row in the file tree

#### File tree & clipboard

- **Ctrl / Shift** multi-select; mixed file/folder copy and delete
- Copy path or copy the real file for Explorer paste; Ctrl+C on a tree selection copies the file
- Logical ordering / cross-folder moves via drag (folders stay above files)
- `_pic` folders cannot be deleted; images inside them can
- Expanding folders survives **F5** reload
- Closing the last tab leaves a blank workspace; double-click the tab bar to create a note in the focused folder (or vault root)

#### Images & undo

- Selected Markdown image: **Copy** / Ctrl+C writes image **binary**; **Copy as plain text** keeps the Markdown link
- Undo after deleting an image can restore the file from a session cache when the note references it again
- Markdown undo history is preserved across tab switches (editor keep-alive)

#### Window & search

- Toolbar **always-on-top** toggle
- Global search (**Ctrl+Shift+F**): keyboard navigation, one-line body snippets with bold red keyword highlight, absolute path under each hit
- Search matches **body text only** (not file path, title, images, or link URLs); selecting a result jumps to the matching line
- Quick open / search selection syncs highlight in the file tree

#### UX polish

- Confirm dialogs: Enter confirms, Escape cancels (does not type into the editor)
- Smoother tab switching (narrower subscriptions, less full-tree churn)
- Welcome page removed in favor of a blank workspace

### Upgrading from v0.4.0

- No vault migration required; existing notes and `_pic` folders are unchanged
- New UI settings (pins, split ratio, outline layouts, file-tree expand state, always-on-top) are stored locally

### Highlights from v0.4.0 (still included)

- Remote / cloud images in Markdown export/import and live paste
- Image captions; `_pic` visibility toggle; file-tree rename and numeric sort
- Markdown bundle export/import; PDF export; plugins (experimental)

### v0.5.0 新内容

#### 左右分屏

- 工具栏提供 **左右分屏**（在窗口置顶旁）
- 多 Tab 时：当前文件分到右屏；仅 0/1 个文件时留在左屏，右屏为空
- 任一侧「关闭所有」**不会**退出分屏，需再点工具栏分屏按钮
- 中间分隔条可拖；左右不可同时打开同一文件
- Tab 可长按拖到另一屏；关闭按钮透明无边框

#### 目录抽屉

- Markdown 目录支持与文件栏相同的抽屉收起
- 左右屏目录宽窄 / 收起状态 **互相独立**
- 进入分屏：两侧目录默认收起；单屏：目录默认展开

#### 置顶区域

- 文件树上方的链接式 **置顶区域**（不移动真实文件）
- Markdown / Excalidraw 右键置顶；可拖拽排序；可从文件树拖入置顶
- 置顶区支持多选与批量取消置顶；再次置顶可移到最前
- 无置顶项时隐藏；与文件列表上下相邻，不再叠盖
- 点击置顶项会同步高亮文件列表中的对应文件

#### 文件树与剪贴板

- **Ctrl / Shift** 多选；文件与文件夹可混合复制 / 删除
- 可复制路径，也可复制文件本体到资源管理器；文件树 Ctrl+C 默认复制文件
- 逻辑排序与跨文件夹拖动（文件夹始终在文件上方）
- `_pic` 文件夹不可删，其内图片可删
- **F5** 刷新后保持文件夹展开状态
- 关掉最后一个标签留下空白工作区；双击 Tab 栏可在选中目录（或根目录）新建笔记

#### 图片与撤销

- 选中 Markdown 图片：**复制** / Ctrl+C 写图片二进制；**复制为纯文本** 保留 Markdown 链接
- 删除图片后再撤销，可在同会话内按需从缓存写回磁盘
- 切换标签时保留 Markdown 撤销栈（编辑器保活）

#### 窗口与搜索

- 工具栏 **窗口置顶**
- 全局搜索（**Ctrl+Shift+F**）：上下键选择、正文摘要行、关键字加粗红色、下方绝对路径加粗
- 仅匹配正文（不含路径 / 标题 / 图片与链接目标）；选中结果跳转到对应行
- 快速打开 / 搜索选中后同步文件列表高亮

#### 体验优化

- 确认框：回车确认、Esc 取消（不会把回车打进编辑器）
- 切换标签更顺滑
- 去掉欢迎页，改为空白工作区

### 从 v0.4.0 升级说明

- 无需迁移知识库；现有笔记与 `_pic` 目录保持不变
- 置顶列表、分屏比例、目录布局、文件树展开、窗口置顶等新设置保存在本地

### v0.4.0 已有能力（本版保留）

- 远程 / 云端图片导入导出与实时粘贴
- 图片描述、`_pic` 显示开关、文件树重命名与数字排序
- Markdown 包导入导出；PDF 导出；插件（实验性）
