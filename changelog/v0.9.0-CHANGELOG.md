# Chestnut Editor v0.9.0

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器 —— 更顺手的表格与全文搜索、更稳的图片与图钉悬浮。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

|------|------|

### v0.9.0 新内容

#### 表格

- 用 GFM 悬浮工具条替代 Crepe 表格块，编辑更接近普通 Markdown 表格
- 支持类似 Excel 的合计与平均值；写入的 **Sum** / **Avg** 标签自动加粗
- 选区包含最左列且在新行写整列合计/平均值时，左侧加一列放置 Sum/Avg，避免覆盖第一列结果
- 表格单元格右键：删除当前行 / 列、向左 / 右插入列、向上 / 下插入行（以右键所在格定位）
- 实时与源码侧增加表格相关提示

#### 搜索与写作

- Markdown 编辑器支持 **Ctrl+Shift+F** 全文搜索（避开 WebView2 加速键与输入法 `Process` 键干扰）
- **Ctrl+Tab** 在当前笔记的源码 / 实时预览之间切换
- 选区消失后自动收起 Markdown 格式工具栏
- 增加 Markdown 字数等写作统计
- 顶栏 Logo 旁显示当前版本号（如 `v0.9.0`）

#### 图片与图钉悬浮

- 保存时将库外本地图片纳入笔记资源目录；网络图片默认保留原链接
- 导出 Markdown 前先 flush 并收纳外部图片
- 图钉按钮与窗口置顶使用同一图标，文案为「图钉悬浮」
- 悬浮窗图片铺满、无多余遮罩；拖边框按原图比例放大缩小

#### 字体

- 默认界面字体为微软雅黑，安装包不再包含小赖、悠哉两套增量字体
- 设置里可按需下载小赖（约 21 MB）与悠哉（约 15 MB），下载完不会自动切换；不需要时可卸载

#### 外观

- 顶栏与选中态使用栗棕色强调；Markdown 链接保持蓝色
- 选中的标签页字体加粗，离开后还原
- 编辑区与文件栏灰度对调：编辑区更浅、文件栏略深；当前页签跟编辑区，未选中页签跟文件栏
- 点击笔记标题不再出现焦点边框

#### 文件与标签

- 修复新建笔记偶发套用上一篇标题：后台未命名窗格不再在失焦时改名
- 文件栏支持 Ctrl+X 剪切文件/文件夹；打开笔记后仍保持文件栏焦点，便于继续 Ctrl+C / Ctrl+X
- 可拖动多选的文件和文件夹；拖动时不再自动展开目录
- 粘贴整篇 Markdown 时不再误包成表格
- 自选知识库目录时，不再在旁边另建 `.chestnut` 文件夹
- 过大知识库先打开界面，Markdown 索引在后台进行

#### 保存与外部编辑器

- 与 VS Code 等共用同一文件夹时：未改动的笔记会自动跟上磁盘；15 秒自动保存不会覆盖外部已写入的内容；有本地未保存编辑时 Ctrl+S 仍会写盘
- 取消设置里的「实时保存」，统一为每 15 秒自动保存 + 手动保存，避免未成熟的实时写盘伤到文档
- 笔记标题旁可从磁盘刷新当前文档

#### 编辑

- 实时预览与源码模式切换时，对齐当前可见行与滚动位置
- 图钉悬浮窗支持滚轮缩放（从左上角起算，拖动后不再跳动）
- 顶栏可检查 GitHub 更新，并显示居中进度
- Debug 移到顶栏右侧

#### 插件

- 新增 Chestnut Cat 桌宠插件：安装包不含资源；设置里按需下载（约 18 MB），无需再选 zip 导入
- 点选加载、再点卸载出内存；卸载按钮删除本机插件文件

#### 稳定性

- 数据防丢失门禁（保存 / flush / 仅查看 / 分屏同文件）
- 修复 Ctrl+点击链接被选中两次
- 换到过大目录、网盘或 junction 环时，可能一直停在「正在打开知识库」；递归列出目录现有深度上限，避免无限走
- 顶栏与右上角独立 **Debug**：不依赖知识库挂载，可复制从打开应用到界面出现的启动日志，并另选 / 清除知识库路径后重载
- 修复点击 Debug 无反应：启动日志快照保持稳定，面板叠在主界面之上
- Debug 与主界面 DOM 隔离，调试组件失败不会再导致整窗白屏

### 从 v0.8.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files — smoother tables and in-note search, more reliable images and floating pins. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.0

#### Tables

- Replace the Crepe table block with a GFM overlay toolbar
- Excel-like sum and average; **Sum** / **Avg** labels are written in bold
- When a column result row would overwrite the leftmost selected column, insert a left column for the Sum/Avg label
- Right-click a table cell to delete the current row or column, insert a column left or right, or insert a row above or below
- Live/source hints around table editing

#### Search & writing

- **Ctrl+Shift+F** full-text search in the Markdown editor (works around WebView2 accelerators and IME `Process` keys)
- **Ctrl+Tab** toggles the current note between source and live view
- Hide the Markdown format toolbar when the selection is dismissed
- Markdown writing stats
- Toolbar logo shows the current version (e.g. `v0.9.0`)

#### Images & floating pin

- On save, ingest local images outside the vault; keep network image URLs by default
- Flush and ingest before Markdown export
- Pin control uses the same icon as window always-on-top; label is “Floating pin”
- Pinned image fills the window with no extra chrome; drag the border to scale at a fixed aspect ratio

#### Fonts

- Default UI font is Microsoft YaHei; Xiaolai and Yozai are no longer shipped in the installer
- Download them on demand in Settings (~21 MB / ~15 MB). Downloading does not switch the font automatically; they can be uninstalled

#### Appearance

- Chestnut accent on chrome and selection; Markdown links stay blue
- Selected tabs use bold type, then return to regular weight
- Swap editor and file-tree grays: the editor is lighter, the file tree slightly darker; the active tab matches the editor, inactive tabs match the file tree
- Clicking the note title no longer shows a focus ring

#### Files & tabs

- Stop keep-alive Untitled panes from renaming a newly created note after blur
- Cut files and folders in the file tree with Ctrl+X; keep file-tree focus after opening a note so Ctrl+C / Ctrl+X still copy or cut the files
- Drag a multi-selection of files and folders; dragging no longer auto-expands folders
- Pasting a full Markdown document no longer wraps it into a spreadsheet table
- Picking a vault folder no longer creates a `.chestnut` directory beside it
- Large vaults open the UI first; Markdown indexing continues in the background

#### Saving & other editors

- When sharing a folder with VS Code: clean notes follow disk; 15s autosave will not overwrite an external save; Ctrl+S still writes if Chestnut has unsaved edits
- Realtime save is removed from Settings; everyone uses 15s autosave plus manual save so premature live writes cannot clobber documents
- Refresh the current note from disk next to the title

#### Editing

- Keep the visible line aligned when switching live and source modes
- Mouse-wheel zoom on pinned desktop images (from the top-left, without jumping after a drag)
- Toolbar GitHub update check with a centered progress dialog
- Debug sits at the trailing edge of the toolbar

#### Plugins

- Chestnut Cat desktop pet: not bundled; download on demand in Settings (~18 MB), no zip file picker
- Select to load, click again to unload; Uninstall removes it from disk

#### Reliability

- Data-loss safety gate for save / flush / view-only / same-file split
- Stop Ctrl+click from selecting a link twice
- Opening a huge folder, a cloud-synced path, or a junction loop could stick on “Opening vault…”; directory listing now has a depth cap
- Isolated **Debug** in the toolbar and top-right: copy boot-to-DOM logs without waiting for the vault, and pick or clear the vault path then reload
- Fix Debug clicks doing nothing: cache the startup snapshot and stack the panel above the app shell
- Debug is mounted on its own DOM root so a debug failure no longer whitescreens the app

### Upgrading from v0.8.x

- No vault migration required
