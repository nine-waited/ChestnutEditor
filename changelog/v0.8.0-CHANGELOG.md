# Chestnut Editor v0.8.0

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器 —— 更快启动、更顺手的实时 Markdown 编辑、图片桌面置顶，以及更准确的文件栏多选。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### 下载

| 项目 | 说明 |
|------|------|
| **安装包** | `Chestnut_0.8.0_x64-setup.exe`（Windows x64，NSIS） |
| **系统要求** | 64 位 Windows 10 及以上；缺少 WebView2 时安装程序会自动下载 |
| **默认知识库** | 首次启动打开 `~/.chestnut` |

**构建产物：**

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.8.0_x64-setup.exe`

### v0.8.0 新内容

#### 实时 Markdown 体验

- 链接显示为蓝色；**Ctrl/Cmd+点击** 在默认浏览器打开 `http(s)` 链接，且不会误选中链接
- 实时模式下 **Ctrl+C / Ctrl+X** 默认复制或剪切纯文本
- 标题上下边距在实时与预览中一致
- 光标在标题行时显示灰色 `#` 层级提示
- 从源码视图切回后，代码块不再保持空白
- 图片不再被 Crepe 的 cover/height 样式居中裁切

#### 标签栏

- 长按拖动可在同一分屏内重排标签
- 重排标签或从文件树拖入时，插入位有过渡动画

#### 图片桌面置顶

- 将笔记中选中的图片钉到始终置顶的悬浮窗
- 可拖动移动、右下角缩放、双击关闭
- 不会从笔记中删除图片

#### 文件栏

- 取消聚焦后，Ctrl/Shift 多选不再把编辑区仍打开的文件带入选中

#### 性能

- Mermaid 与 Excalidraw 改为懒加载，启动时不再一并拉入

### 从 v0.7.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files — faster startup, richer Live Markdown editing, desktop image pins, and sharper file-tree selection.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

| **Requirements** | 64-bit Windows 10+; WebView2 (downloaded during install if missing) |
| **Default vault** | `~/.chestnut` on first launch |

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.8.0_x64-setup.exe`

### What's New in v0.8.0

#### Live Markdown polish

- Links render in blue; **Ctrl/Cmd+click** opens `http(s)` URLs in the default browser without selecting the link
- **Ctrl+C / Ctrl+X** copy or cut plain text by default in Live mode
- Heading top margin matches bottom margin in Live and preview
- Gray `#` level hints while the caret is on a heading line
- Code blocks no longer stay empty after switching from source view
- Images no longer get center-cropped by Crepe cover/height styles

#### Tabs

- Long-press drag to reorder tabs within the same pane
- Animated insert slots when reordering tabs or dropping files from the tree

#### Image pin to desktop

- Pin a selected note image to an always-on-top floating window
- Drag to move, corner handle to resize, double-click to close
- Does not remove the image from the note

#### File tree

- Ctrl/Shift multi-select no longer pulls in the file still open in the editor after focus moves elsewhere

#### Performance

- Mermaid and Excalidraw load lazily so they are not pulled in at startup

### Upgrading from v0.7.x

- No vault migration required
