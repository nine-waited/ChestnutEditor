# Chestnut Editor v0.9.5

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器。本版实时模式里，加粗、斜体、删除线、高亮、行内代码和数学公式默认不显示符号；点进去或把光标移进去后，符号就是普通文本。标签四个角都是圆角。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### v0.9.5 新内容

#### 实时编辑

- 加粗、斜体、删除线、高亮、行内代码、数学公式：鼠标悬停不显示符号；点击或把光标移入后，符号以灰色普通文字出现
- 符号显示后，选中、方向键、删除、复制和撤销都与正文相同
- 标题行：点击该行才显示 `#` 前缀，悬停不显示
- 高亮会写入文件，格式为 `==文字==`，与源码模式一致
- 逐个输入加粗的结束星号时，不再被斜体提前吃掉
- 在加粗结束符号后面继续输入时，已有加粗不再闪一下

#### 界面

- 标签四个角都是圆角
- 文件栏工具图标的提示显示在文件列表之上

#### 桌宠

- 应用隔夜开着时，今日字数按本地日期归零

### 从 v0.9.x 升级

- 无需迁移知识库
- 以前只在实时模式里涂上、没有写进文件的高亮，重新打开后不会保留；之后的高亮会保存为 `==文字==`

## English

A desktop editor for local Markdown and Excalidraw files. In this release, live mode hides bold, italic, strike, highlight, inline code, and math markers until you click or move the caret into that text; the markers are then ordinary text. Tabs are rounded on all four corners. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.5

#### Live editing

- Bold, italic, strike, highlight, inline code, and math: hovering shows no markers; clicking or moving the caret in reveals them as gray ordinary text
- Once visible, selection, arrow keys, delete, copy, and undo behave like body text
- Headings: the `#` prefix appears when you click that line, not on hover
- Highlight is saved as `==text==` and matches source mode
- Typing the closing stars of bold one at a time no longer turns the span into italic
- Typing after the closing bold marker no longer drops the bold styling for a moment

#### Interface

- Tabs are rounded on all four corners
- File-bar tooltips draw above the file list

#### Desktop pet

- The daily word count resets on the local date even if the app stays open overnight

### Upgrading from v0.9.x

- No vault migration
- Highlight that was only painted in live mode and never written into the file will not come back after reopen; new highlights are saved as `==text==`
