# Chestnut Editor v0.9.4

---

## 简体中文

面向本地 Markdown 与 Excalidraw 的桌面编辑器。本版文件树可把文件夹拖到文件上/下方，也可拖进文件夹；表格单元格里的 `|` 不再把表格拆坏；后补 `` ` `` / `*` 也能套上样式。默认界面字体为微软雅黑；小赖 / 悠哉在设置中按需下载，不打进安装包。桌宠为可选知识库插件，亦不打进安装包。

Chestnut Editor 在你选择的文件夹中直接读写普通文件，无需专有数据库，也不依赖云端。

### 下载

| 项目 | 说明 |
|------|------|
| **安装包** | `Chestnut_0.9.4_x64-setup.exe`（Windows x64，NSIS） |
| **系统要求** | 64 位 Windows 10 及以上；缺少 WebView2 时安装程序会自动下载 |
| **默认知识库** | 首次启动打开 `~/.chestnut` |

**构建产物：**

`apps/desktop/src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/Chestnut_0.9.4_x64-setup.exe`

### v0.9.4 新内容

#### 文件树

- 文件夹可以拖到文件的上方或下方（不必先进文件夹）
- 拖到文件夹上：上/下边缘是同级排序，中央是移入该文件夹
- 笔记配套的 `_pic` 文件夹跟在对应 Markdown 后面，不能单独拖走
- 右键菜单不再显示「剪切」；`Ctrl+X` 仍然可用

#### 编辑

- 表格格子里写 `(1<<1)|0` 这类 `|` 时，改表格附近的源码不再把表格拆成普通段落；实时模式写出时会转成 `\|`
- 先打字再补开头的 `` ` ``、`*`、`**`、`~~`，也能套上代码 / 斜体 / 加粗 / 删除线
- 向上拖选跨过标题时，不再插入多余的 `#`

#### 图片与下载

- 再点一次已选中的图片会取消选中
- 国内网络从 GitCode 下载字体和桌宠（设置里按需下载，仍不打进安装包）

### 从 v0.9.x 升级

- 无需迁移知识库

## English

A desktop editor for local Markdown and Excalidraw files. This release lets you drop folders above or below files (or into a folder), keeps `|` inside table cells from breaking the table, and wraps inline styles when you type the opening delimiter last. The default UI font is Microsoft YaHei; Xiaolai and Yozai are optional downloads in Settings and are not bundled. The desktop pet is an optional vault plugin and is also not bundled.

Chestnut Editor reads and writes plain files in a folder you choose. No proprietary database, no cloud required.

### What's New in v0.9.4

#### File tree

- Folders can be dropped above or below files, not only into folders
- Dropping onto a folder: the top/bottom edges reorder among siblings; the center moves into that folder
- `_pic` folders stay glued to their notes and cannot be dragged on their own
- Cut is hidden from the context menu; `Ctrl+X` still works

#### Editing

- Pipes inside table cells such as `(1<<1)|0` no longer collapse the table when you edit nearby source; live mode serializes them as `\|`
- Typing the opening `` ` ``, `*`, `**`, or `~~` after the text still wraps code, italic, bold, or strikethrough
- Dragging a selection upward across headings no longer inserts extra `#` markers

#### Images and downloads

- Clicking a selected image again clears the selection
- Fonts and the desktop pet download from GitCode on networks in China (optional in Settings; still not bundled)

### Upgrading from v0.9.x

- No vault migration required
